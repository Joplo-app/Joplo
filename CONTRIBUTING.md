# Contributing to Joplo

[中文](#参与-joplo)

**Joplo accepts issues, not pull requests.** Bug reports, feature requests, questions, and feedback on the docs or the skills are all welcome. Pull requests from outside the core team are closed without review.

Joplo is licensed under [PolyForm Shield 1.0.0](LICENSE), and the core team writes all of its code. That keeps licensing simple and lets us change the design quickly. If you have a fix in mind, describe it in an issue, and include a patch or code snippet if that helps explain it.

## Open an issue

[Open an issue](https://github.com/Joplo-app/Joplo/issues/new/choose) and pick a template:

- **Bug report:** what you ran, what you expected, and what happened. Include `npx joplo --version`, your OS and Node version, and the smallest project or snippet that shows the problem. `npx joplo check` output helps.
- **Feature request:** the problem you are trying to solve and who runs into it. Describe the problem before the solution.

Search the existing issues first. If one already covers your problem, add a 👍 or a comment with new details.

## Security issues and licensing questions

Do not report security issues in public issues. Email [support@joplo.app](mailto:support@joplo.app) instead. Send questions about licensing or other commercial terms ([COMMERCIAL.md](COMMERCIAL.md)) to the same address.

## Ideas and code in issues

By posting suggestions, code, or other material in an issue, you agree that the Joplo licensor may use it in Joplo and license it under any terms.

# 参与 Joplo

**Joplo 接受 issue，不接受 pull request。** 欢迎提交 bug、功能需求、使用问题，以及对文档和技能的意见。核心团队以外的 PR 会直接关闭，不做评审。

Joplo 的许可证是 [PolyForm Shield 1.0.0](LICENSE)，所有代码都由核心团队编写。这样许可证关系简单，设计也能快速调整。如果你想到了修复办法，请在 issue 里描述；附上补丁或代码片段能说得更清楚的话，也可以一起贴上。

## 提交 issue

[新建 issue](https://github.com/Joplo-app/Joplo/issues/new/choose)，然后选择模板：

- **Bug 报告**：你运行了什么、预期结果是什么、实际发生了什么。请附上 `npx joplo --version`、操作系统和 Node 版本，以及能复现问题的最小项目或代码片段；`npx joplo check` 的输出也有帮助。
- **功能需求**：你想解决什么问题，谁会遇到它。先讲问题，再讲方案。

提交前先搜一下已有的 issue。如果已经有人提过同样的问题，点个 👍，或者在评论里补充新的细节。

## 安全问题和授权咨询

安全问题不要发在公开的 issue 里，请发邮件到 [support@joplo.app](mailto:support@joplo.app)。授权或其他商业条款的问题（见 [COMMERCIAL.md](COMMERCIAL.md)）也发到这个邮箱。

## issue 中的想法和代码

在 issue 中发布建议、代码或其他材料，即表示你同意 Joplo 的许可方在 Joplo 中使用这些内容，并以任何条款授权。
