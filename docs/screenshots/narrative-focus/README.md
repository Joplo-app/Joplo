# 叙事焦点：camping 样板前后对比（D67）

`*-before.png` 是 0.2.7（改造前）的 `npx joplo render`，`*-after.png` 是改造后同一处的截图；05、06 是本地看板播放时的动画中间帧（只截舞台）。

| 图 | 这一步 | 改造前 | 改造后 |
| --- | --- | --- | --- |
| 01-context | 开场后的第一步 | 直接开始输入，观众不知道这一屏有哪几块 | `numbered('chat_col', 'plan_col')` + `hold(4)`：先说清左边对话、右边行程单（先上下文后细节） |
| 02-conclusion | 助手给出结论 | `shot('msg_reply')` 推近 2 倍，右边的行程单被裁掉，字幕却说“行程单放在右边” | `spotlight('msg_reply')` + `callout(…)`：整屏可见，只照亮结论，便签说明为什么 |
| 03-share | 行程单完成 | 手绘箭头标注压在行程单边框上 | `callout('share', '生成完才能分享')`：便签放在按钮左侧，引线指向按钮 |
| 04-update | 行程单升到 v2 | 方框标注与镜头高光叠在整张行程单外沿，说明文字被挤到画面底边、和字幕挤在一起 | `callout('plan_title', …)`：便签指向标题，不和字幕抢位置 |
| 05-reveal | 阿杰点「我能去」 | 提示条出现，没有任何提示 | 默认的结果揭晓：新出现的提示条外沿亮一下再淡出 |
| 06-establish | 小雨分享后切到「行程数据」层 | 镜头从上一层的推近视图直接过渡 | 默认的先全景再推近：先停在整层（-1），再推近到状态与数据卡（-2） |
