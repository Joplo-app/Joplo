# 待做：体现新交互能力的示例（2026-11-08 记录）

背景：插件平台（D87）与交互能力（P1-D：自由体验 / 游玩层、拖拽 / 悬停 / 滚动等新动作、跨场景跳转）完成后，用两个示例展示“看起来像视频，但可以像网页一样交互”，并做多模态内容。之前效果好的参照：`examples/midterms-2026`（选题有时效、新闻快剪节奏、专门画的数据图形）。

现有能力的限制：状态只能“设置”，不能“计算”（没有求和、计数这类派生值），所以“随便拖、实时算”的模拟做不了；“观众做一个选择 → 故事走向对应分支”可以，用跨场景跳转与 `flow({ from })` 接力实现。

## 示例 A：《同一个按钮的 40 年》（用户选定，不需要新能力）

一个“发送”按钮从 1984 年的 Mac、1995 年的 Windows、2007 年的 iPhone，一路变到今天的 AI 输入框。

- 像视频：每个年代一套界面主题（插件主题 CSS），同一个按钮用 `motion` 从上一个年代变形飞进下一个年代；每个年代一段 Alda 配乐（80 年代芯片音乐……），旁白讲这个年代的交互范式。
- 像网页：暂停在任何年代，那个年代的界面真的能用（点开开始菜单、在旧手机上打字）——组件原生行为 + 作者声明的自由反应。
- 拖动底部时间轴直接跳到任意年代（拖拽动作 + 跨场景跳转）。
- 用到：content 插件（Canvas、camera、motion）、插件主题、Alda、自由体验、拖拽、跨场景跳转。
- 注意：各年代界面用自己画的低保真风格，不复制具体系统的图标与商标。

## 示例 B：《一颗苹果的旅程》（需要先做能力 P1-E）

同一个 3D 苹果始终在画面中央，每到一个时代就变成那个时代的样子。

| 时代 | 苹果变成 | 观众暂停后可以 |
|---|---|---|
| 远古：天山野苹果林（所有栽培苹果的祖先在哈萨克斯坦一带） | 青涩的小野果 | 旋转观察；悬停看起源 |
| 神话：伊甸园的“禁果” | 金色、发光的果子 | 点它看“禁果原文没说是苹果”的翻译误会 |
| 1666：牛顿的苹果树 | 从树上掉下的苹果 | 把苹果拖下去，“发现”引力 |
| 童话：白雪公主的毒苹果 | 一半红、一半带毒 | 咬一口，进入“为什么是苹果”的分支 |
| 1976–今天：苹果公司 | 早期标志的故事、彩虹苹果、单色 | 拖动时间轴在几代之间切换 |
| 结尾：你手里的手机 | 苹果落进屏幕 | 回到任意时代 |

- 多模态：每个时代的苹果用 Tripo3D 生成 3D 模型；每个时代一段 Alda 配乐（远古笛子、牛顿时代大键琴、童话八音盒、现代合成器）；旁白；讲解画布的镜头与变形转场。
- 事实需要开工时核实（苹果起源、禁果的翻译、牛顿苹果故事的出处、苹果公司早期标志的历史，以及“图灵与咬一口的苹果”这类流传说法要辟谣而不是当事实）。

### 需要先做的能力 P1-E

1. scene3d 加载真实 3D 模型（GLB）：组件属性引用模型资源；运行时用 GLTFLoader；二进制资源能内嵌进发布站（`asset()` 现在只支持图片）；截图等待模型载入（`ctx.hold()`）；注意发布站体积。
2. Tripo3D 插件（本机能力，复用 P1-B 的资源编译器机制）：作者在源码写一句描述（或给参考图），本机调用 Tripo3D API 生成 GLB。API 的接口、计费、任务轮询方式开工时以官方文档为准。

### 用户已定（2026-11-08）

- 生成的模型**写进项目、进 Git**：生成一次后保存到项目的 `assets/models/`（按描述哈希命名），换电脑、队友构建都用同一个模型，不重新生成、不会变；描述改了才重新生成（花钱前提示）。和 Alda 只在本机缓存不同，原因是 Tripo 生成要花钱、而且同一句描述每次结果不同。
- API Key **和朗读供应商一样管理**：看板里保存到本机 Joplo 配置（~/.joplo），不进项目和 Git；也支持环境变量 `TRIPO_API_KEY`。
- 版权与商标：**只用公有领域与自己的风格**。白雪公主按格林童话原著（公有领域）画，不用迪士尼 1937 年版形象；苹果公司部分用自己画的“被咬一口的苹果”剖影讲故事，不精确复制商标。
