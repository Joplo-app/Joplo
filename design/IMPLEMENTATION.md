## 不变量（每个阶段都要守住）

1. **一屏放下**（D43）：1280×800、1440×900 下页面不滚动；窄屏按 `34` 的顺序收起，控件文字不换行。
2. **网址就是状态**：现有 hash 路由的含义不变（`o / c / s / step / l / speed`）。新增的界面状态（浮层开关、悬停、检查模式）不写进网址。
3. **点击只改变“看什么”**：除了检查选中（写 `.joplo/selection.json`）和外观设置（写 `settings.json`），看板不写任何文件。
4. **手动、逐步、自动播放、回放、截图、视频、发布站共用同一套状态逻辑**（AGENT-HANDOFF 的质量边界）。时间线跳步沿用现有的 `clickStepChip` 语义。
5. **创作侧信息不进发布站**（D33）：缺口、规则、AI 假设、检查、外观、导出视频只在看板里，并且只通过 `PlayerPage` 的 `nav / banner / drawer / menu` 等参数传入（沿用现有边界，`PlayerPage.tsx` 顶部注释）。
6. **舞台主题与看板界面分离**：看板界面只用新的看板 Token（例如 `--jb-*`）；舞台、字幕、手机外框继续只读 `--jp-*`。字幕区跟随舞台主题，播放控制不跟随。
7. **颜色不单独表意**：覆盖状态一律“图标 + 文字或悬停全称”（✓ circle-check / ✕ circle-x / 待决定 circle-dashed / 不适用 circle-minus）。
8. **浮层只有一种**（e1：1.5px 墨线 + 3px 实色偏移阴影，圆角 10），用 portal 渲染，不能被父级的 `overflow` 裁掉。现在「…」菜单被播放控制行的 `overflow-hidden` 裁掉、点了看不见，这是已知 bug，重做时一并修掉。

## 外观：配色 / 字体 / 线条拆开（新增字段的端到端流向）

- **配色**：仍是现有的主题名（`themes.ts` 的内置主题 + 作者 `themes/*.css`）。`sketch` 与 `clean` 的配色相同，在格子里合并显示为一个「纸白」：当前主题是 `sketch` 或 `clean` 时这一格都显示为选中，再点一次不写入；从别的配色点「纸白」写 `sketch`。共 8 格内置配色，加上作者主题，最后一格是「+ 自定义」（打开 `docs/themes.md` 的说明，或者复制 `themes/<名字>.css` 的模板）。
- **字体**（新增）：`null`（跟随主题）| `hand`（Excalifont + 小赖，已打包）| `sans`（系统黑体）| `serif`（系统宋体栈）| `kai`（系统楷体栈）| `mono`。只用本机字体，不新增字体文件。
- **线条**（新增）：`null`（跟随主题）| `rough` | `clean`。
- 流向，每一段都要有测试：
  1. **写入点**：外观浮层 → `PUT /__joplo/settings`；
  2. **存储**：`<JOPLO_HOME>/settings.json`，`BoardSettings` 扩展为 `{ version, theme?, font?, stroke?, projects?: { [id]: { theme?, font?, stroke? } } }`。旧文件（只有 `theme`）照常读取。服务端 `normalizeSettings` 校验并丢弃非法值；
  3. **读取点**：`useBoardSettings` 和 `effectiveTheme`（扩展为 `effectiveAppearance`，返回 `{ theme, font, stroke }`）。优先级不变：本项目 > 所有项目 > 项目 config；字体和线条为 `null` 时取主题自己的值；
  4. **消费者**：
     - 舞台根节点和 `.jtheme` 部件（字幕、手机外框）：`data-theme`、`data-stroke`，字体用 `--jp-font` 覆盖；
     - 导出图片和视频：请求体增加 `font`、`stroke`，`render.ts` 透传给渲染页；
     - `renderStep`：缺省时沿用项目主题。
- **发布站不支持字体和线条**（用户决定，以后统计支持的字体再说）：`joplo.config.ts` 仍只有 `theme`，浮层底部写明这一点，并提供“复制 theme”。
- 浮层的交互：
  - 打开：按钮或 `T`；关闭：点外面或 `Esc`；
  - 应用：点一下立即应用并保存；
  - 预览：悬停 150ms 临时预览，移开恢复；
  - 键盘：方向键移动，`Enter` 应用，`Esc` 关闭并恢复预览前的外观；
  - 其他操作：「恢复项目默认」、「设为所有项目的默认」。
- 旧的设置页 `#/settings` 改为跳转到首页并打开外观浮层（所有项目范围）。

2. **演示页结构**：
